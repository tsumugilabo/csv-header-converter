# csv-header-converter — CSVヘッダー変換ツール

ネットショップや業務システムからダウンロードしたCSVの**列名を付け替え、不要な列を削除し、固定値・連番の列を足して**、
別のシステムに取り込める形へ変換するツールです。**インストール不要**。`index.html` をブラウザで開くだけで動きます。

データはブラウザの中だけで処理し、外部には送信しません。

## できること

| 課題 | 対応 |
|---|---|
| 取り込み先と列名が違う | 出力列ごとに「元の列」を選んで付け替え |
| 不要な列が多い | 出力に指定した列だけが残る（指定しなければ出ない） |
| 全行に同じ値を入れたい（店舗コード・ステータスなど） | 「固定値」の列 |
| 1注文に複数商品があり、明細ごとに番号が要る | 「連番」の列。注文番号ごとに 0001, 0002… と数え直せる |
| 住所が2列に分かれている | 「複数の列をつなぐ」 |
| 文字コードがバラバラ（UTF-8 / Shift-JIS） | 読み込み時に自動判定。出力はShift-JIS／UTF-8を選べる |
| 郵便番号・電話番号の先頭の0が消える | 値はすべて文字列のまま扱うので消えない |
| 入力に無い列名を指定してしまった | 警告を出して空欄で出力（黙って壊れない） |

## 使い方

1. `index.html` をブラウザで開く
2. 変換前のCSVをドラッグ（または選択）
3. 出力する列を設定する。初めての場合は「サンプルの設定を読み込む」を押すと例が入ります
4. 「変換する」でプレビュー、「CSVをダウンロード」で保存

設定は「設定を保存（JSON）」で保存でき、次回は「設定を読み込む」で再利用できます。
毎回同じ形式のCSVを変換する用途なら、設定ファイルを1つ作れば以後はCSVを放り込むだけです。

> 「サンプルの設定を読み込む」は `examples/` を読みに行くため、ファイルを直接開くと使えないブラウザがあります。
> その場合は「設定を読み込む」から `examples/sample-rules.json` を選んでください。

## 設定ファイル（JSON）

```json
{
  "columns": [
    { "name": "店舗コード", "type": "fixed", "value": "SHOP001" },
    { "name": "注文番号",   "type": "source", "from": "伝票番号" },
    { "name": "注文者住所", "type": "join", "from": ["注文者住所1", "注文者住所2"], "sep": "" },
    { "name": "明細番号",   "type": "seq", "start": 1, "pad": 4, "groupBy": "伝票番号" },
    { "name": "備考",       "type": "blank" }
  ]
}
```

| type | 意味 |
|---|---|
| `source` | 元の列をそのまま（`from`） |
| `join` | 複数の列をつなぐ（`from` は配列、`sep` は区切り。空の列は飛ばす） |
| `fixed` | 全行に同じ値（`value`） |
| `seq` | 連番（`start` 開始値、`pad` 桁数、`groupBy` を指定するとその列の値ごとに数え直す） |
| `blank` | 空欄 |

## 構成

- `index.html` — 画面
- `core.js` — 変換ロジック（CSVの読み書き、文字コード判定、Shift-JIS書き出し、変換）。ブラウザでもNodeでも動く
- `examples/` — サンプルの入力CSVと設定
- `test/core.test.js` — テスト

外部ライブラリには依存しません。Shift-JISへの書き出しは、ブラウザ標準の `TextDecoder` から符号化表を組み立てています。

## テスト

```bash
node --test test/core.test.js
```

## 制約

- 変換の仕様はこの設定ファイルで決まります。取り込み先ごとの細かい検証（桁数・必須項目のチェック等）はしません
- 数十万行を超える大きなCSVは、ブラウザのメモリに依存します
